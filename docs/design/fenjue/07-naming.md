# 07 命名方案

> 焚决设计 v0.1 的第七篇。上位：[README](./README.md)。

## 1. 总则

1. **产品仍叫庖丁，焚决是庖丁的进化架构。** 全称“庖丁·焚决”。仓库、包名（`paoding_*`）、事件里的任何标识都不改。理由：改名不带来任何能力，却会碰到事件账、导出物、已有文档的大量引用；而且两个名字讲的是两件事：庖丁讲“怎么解一道题”（依乎天理、批大郤），焚决讲“系统自己怎么变强”（吞火、炼化、进阶）。是否整体改名见 FJ1。
2. **两套典故各管一层，不混用。** 解题这一层继续用《庄子·养生主》的名字（解牛图、锦囊、如意、谛听、八仙过海、复盘、通鉴、四顾、善刀）；进化这一层用焚决的名字。一个组件只有一个名字：比如司南仍叫司南，它装着的那团编排火叫 `h2.sinan`，不另起一个焚决式的别名。
3. **名词只在设计文档与代码标识里出现，界面上不出现。** 人在工作台上看到的是“第 2 阶”“这次改进的读数”“撤回到上一版”这样的平常话。唯一的例外是读数页的“焚决”一栏标题。这与界面禁用“开题/关题”一类内部词的做法一致。
4. **代码标识用拼音或对照英文，与现有组件同一习惯**（`sinan`、`shuku`、`tongjian`、`qicao`）。

- **体质修炼**：增强体质的单独流程，走规格变更表，不经吞噬协议（[01 §7](./01-boundary.md#7-体质修炼不经吞噬协议)）。

## 4. 被否掉的名字

| 名字 | 为什么不用 |
| --- | --- |
| 把信任内核叫“丹田” | 丹田是斗气的储存处，会让人以为内核是“存能力”的地方；体质强调的是“承受”，与守门的意思对得上 |
| 把回滚叫“退火” | 退火在冶金里是让材料变好的工艺，会被读成“优化”，与撤回的意思相反 |
| 把功法版本叫“斗之气、斗者……”一类境界名 | 境界是人的修为，不是功法的品阶；也太长，不适合当版本号 |
| 把每个火位起一个异火名 | 名字会喧宾夺主，让人以为火位绑定某一种火；火位应该是中性的槽 |
