# 庖丁·焚决：以融合为进化之道的架构转型（设计 v0.1，待裁决）

> 起因：cz 2026-11-20 设计任务“焚决：以融合异火为进化之道的智能体框架”。这几天每吸收一个新能力都改一次内核（入口拒题、会话形态、无答案键的判据、外部时限、活动不可见），这是打补丁，不是进化。要的是一次架构转型：信任内核不动，能力层可识别、可校验、可替换，外部的好做法经一个标准的炼化流程吸收，融合出单一来源造不出的新能力。
>
> 本稿只出设计与命名，不含实现代码。§5 列出待裁决项 FJ1–FJ15，每项附推荐。
>
> 依据 `main` 17b2217（#113 已合）。在途未合的按“即将落地”对待并逐处注明：#105 续期门、#111 地图 v0.9–v0.10 与 L3 第三步（待裁 D9–D14）、#114 资料库第二期、#115 会话活动面板。
>
> 硬约束：信任内核五项不可绕过；已有事件回放逐字节不变；已合入功能不丢；不读取任何本机题库、评测或校准目录；预算先验走可插拔数据源，本稿所有默认数字都是〔占位〕。

## 0. 一页结论

1. **三分，不是两分。** 体质（信任内核，五项不可变）、功法（能力层，八个火位，可替换）、药鼎（量具：读数、评测台、体质试炼）。量具单列的理由只有一句：**被度量的东西不得修改度量它的尺子**，否则“吞了变强”无从证明（[01 §2](./01-boundary.md#2-三个部分不是两个)）。
2. **体质五项**对到现有的不变量与强制点：判（I2、I4）、闸（I5 与钥匙环）、顶（I6）、账（I1、I3）、证（I2、I7、I8）。体质对功法只开七条经脉，每一条今天都已经存在，焚决不新开端口（[01 §3–§4](./01-boundary.md#3-体质五项)）。
3. **功法有八个火位**：会话形态、编排、工具面、上下文、知识源、观察面、报告形态、起草。今天每个火位都已经装着火，只是散在 `if role == "solve"` 这类分支里。焚决把它们写成带清单、带摘要、带开关的“火”（[01 §5、§8](./01-boundary.md#5-功法八个火位)）。
4. **席位与形态分开**，这是“不再每次改内核”的关键一刀：内核只认现有的七个席位（`role`）作为权能上限；新的会话形态绑定已有席位，不动内核；真需要新席位才算体质修炼（[01 §6](./01-boundary.md#6-席位会话的权能上限)）。
5. **吞噬协议六步：识火、萃意、入位、验体、融火、散火。** 前三步是设计稿，裁决后才写代码；验体是确定性的体质试炼（T1–T5 对抗剧本，不调模型）；融火跑对照读数；散火是常备的一键回滚。每次一份炼档（[02](./02-lianhua.md)）。
6. **萃意是最重要的一步**：吞的是“火意”，一句不提实现的本质，不是代码。检验方法：把出处遮住，设计还成立吗（[02 §4](./02-lianhua.md#4-第二步萃意提炼火意)）。
7. **火莲判据**照四臂思想设五条臂：本火 B、异火单炼 A′、合火 F、同火对照 B′（噪声底）、原形参照 A°（只作参考）。四种结局：**火莲**（出现两源按构造都为零的新生维）、**合炼**（同维度胜过两源）、**并火**（只是收藏，不收）、**反噬**（体质不过或本火维退步，不收）。读数与门槛在写代码前预登记（[03](./03-huolian.md)）。
8. **进化度量**：体质试炼是门（永远 100%）；严格道四臂照旧，G1 口径不动；开放道用吞噬前后同一组提示词配对对照，加 cz 的盲评；入功法后上一团火进常设留出，跌破门槛出反噬告警，散火由人决定（[04](./04-evolution.md)）。焚决自己的生死线是**体质改动行数**：吞噬要做到不改内核。
9. **首炼推荐“可回放的实时性”**：#115 就是它的异火单炼 A′；合火只加三处（条目成链、分段以 authored 类入账、执行行可点到留档），**体质改动 0 行**，三条新生维都按构造为零，有资格判火莲（[05 §1](./05-cases.md#1-案例一可回放的实时性)）。
10. **迁移五步**：F1 体质试炼与按道补录黄金日志 → F2 火位立名（零差迁移，品阶 1）→ F3 功法摘要入开题事件（焚决自身唯一一次体质修炼）→ F4 首炼 → F5 炼档流程化。旧事件一条不改写，信封不升版，新字段只加可选的，缺省值在读端推（[06](./06-migration.md)）。

## 2. 与庖丁现有设计的关系

- **三层六契约**（规格 2.1）：体质 = 信任根 + 协调基质 + 会话边界里的守门部分（端点代理、钥匙环、双容器、代理工具的校验）。功法 = 规格第 4 节的外壳机制 + 会话边界里的感知部分（提示词、任务包、工具面的组合）+ 起草 + 观察面。三层的划分不变，焚决是在它之上把“外壳”整理成可替换的火位。
- **官知止**（总纲 v1.2）：焚决不是它的反面。功法里每团火都是一个官，照旧回答入库四问；守门官只在体质。官知止说“退位即进化”，焚决说“吞噬即进化”，两者在品阶上同记一笔，用同一套读数（FJ12）。系统变强的方式有两种：吞进更好的做法，或撤掉模型已经不需要的器官。
- **红线 5 诚实对照**：火莲判据是它在“吸收”这件事上的形态。融合的产物赢不过照搬（并火）就不收，赢不过本火就不收。
- **工作台地图**（宪章 v0.5，#111 在途改到 v0.10）：焚决不加站，不改地图。#111 合入后由地图线出一次修订，站表加一列“火位”。改变人看到的流程的吞噬，照旧走地图修订规程。
- **开放道**：开放道本身就是一次没有协议的吞噬。[05 §0](./05-cases.md#0-案例零补档-000一个会话做到底) 按六步给它补了档，暴露两件事：吞噬与体质修炼混在一个 PR 里；没有异火臂。
