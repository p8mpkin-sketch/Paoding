# 度量与证明计划

> 上位文档：[README](./README.md)。规则沿用规格 8.3：先跑对照臂、冻结阈值、预登记进评测题组，不在看到结果之后移动球门。

## 1. 证据现状与前提

| 读数 | 来源 | 状态 |
| --- | --- | --- |
| q1 baseline（单 CLI）0/3 | `docs/m1/readings/2026-11-18-first-comparison.md` | **作废**：环境缺陷（宿主上解析不了题目容器、没有 Bash、没说交付方式），PR #74 修复 |
| q1 baseline 对等重跑 5/5，均 25.5 秒、$0.0118 | PR #75（原始记录） | 待合入；本文按它计 |
| q1 full 3/3，均 30.7 秒、$0.016 | 同第一份读数 | 有效 |
| Bk、Bn、20 题、G1 到 G3 | — | 都还没有 |

由此得出两条前提，三项能力的证明计划都按它们设计：

1. **G1 未证明。** 易题上厚路径比薄路径贵 36%、慢 20%，解题率相同。三项能力的增量必须分别在薄路径与厚路径上量，不能默认"厚路径 + 新能力"是唯一形态。
2. **样本极小。** 现有题只有 q1、q2。每项能力都要专门的题组；本文给出题组的结构要求，题目本身由评测线程准备。按规格 8.6 的粗算（单侧 90%、功效 80%），12 对配对样本只能检出约 30% 的节省率差异，所以本计划的阈值都定在这个量级之上，结论一律标"方向性"，M3 扩到 30 对再复核。

## 2. 题组

| 题组 | 结构 | 用于 | 规模（最小版本） |
| --- | --- | --- | --- |
| R：复做题组 | 每个模板两个实例 A、B，A 先跑完关题，B 再跑。B 的答案与随机参数（凭据、文件名、端口号之外的值）必须不同于 A。一半模板的 B 与 A 同 `env_key`（R-same），一半换目标（R-diff）。R-same 里再派生"漂移"变体 B'：A 时为真的环境事实改掉约 30% | 能力一、二 | 12 个模板 × (A + B + B') |
| I：导入题组 | 同签名 20 题：10 题作"标准案例"导入练习，另 10 题作新题 | 能力二的导入路径 | 1 个签名 × 20 |
| D/C：并行题组 | D 可分解：Goal 需要 ≥ 3 个互不依赖的子判据；C 强耦合：子判据成链 | 能力三 | 各 8 题 |

题模板与实例生成器是评测台的事（`eval/problems.d` 加模板参数），不进内核。复做题组要求"换答案"是硬条件：同答案的复做测的是检索，不是经验。

## 3. 能力一、二：臂与消融

**主矩阵**（R 题组的 B 实例，每格 3 次）：

| 臂 | 路径 | 记忆召回 | 投影资产 | 读数主要回答 |
| --- | --- | --- | --- | --- |
| 冷·薄 | 单 CLI（B1） | 关 | 关 | 薄路径第二次有多贵 |
| 笔记·薄 | 单 CLI，A 的最后输出原文贴进提示 | — | — | 诚实基线：最朴素的"记忆" |
| 记忆·薄 | Bootstrap 单独跑（`bootstrap_share=1`），召回在前 | 开 | 关 | 记忆对薄路径的增量 |
| 冷·全 | 全栈 | 关 | 关 | 对照 |
| 记忆·全 | 全栈 | 开 | 关 | 能力一 |
| 资产·全 | 全栈 | 关 | 开 | 能力二（R-diff 上最干净） |
| 全开 | 全栈 | 开 | 开 | 合计，及二者是否互相替代 |

**消融**（只跑 R-same 与 B'）：`recall_noverify`（复核这道守门官的价值，看污染率）；`-check_tpl`、`-cut_prior`、`-spend`（单资产各关一个）。

**导入路径**（I 题组）：导入 10 题并练习 → 跑另 10 题；对照是同 10 题不导入；消融是"导入即资产"（跳过练习，直接把参考解法当锦囊），并在其中注入 2 个错误标准案例。

**读数**（每格）：解题率；token 三项（输入、输出、缓存读）与美元；墙钟；召回命中率与在链率；污染率；切口命中率（规格 8.4）；折损率。主口径是复做节省率 S（[能力二](./02-experience.md) §5.1）。

**预登记阈值**（合并自能力一 §7、能力二 §5.3）：

| # | 判据 | 不达标的动作 |
| --- | --- | --- |
| P1 | 记忆·全对冷·全：R-same 上 S_tok ≥ 25%、S_wall ≥ 15%，解题率不降一题以上 | 召回不进 M3，只留判例 |
| P2 | 记忆·薄对冷·薄：同上 | 召回只服务厚路径；若 P1 也不达标，同上 |
| P3 | 记忆的两条臂中较好的一条，在 S_tok 或污染率上优于笔记·薄 | 赢不了"贴笔记"就删召回，通鉴只留判例（红线 5） |
| P4 | B' 上 `recall_noverify` 的污染率显著高于记忆·全，且记忆·全的污染率不高于冷·全 | 前者不成立：复核只是成本，改为抽样复核；后者不成立：召回本身在污染，停用 |
| P5 | 资产·全对冷·全：R-diff 上 S_tok ≥ 15%、S_wall ≥ 10%，解题率不降一题以上 | 投影资产不进 M3 |
| P6 | 单资产消融：S_tok 下降 < 3 个百分点的资产 | 在 M3 删除该资产 |
| P7 | 导入后新题对未导入：S_tok ≥ 15% | 导入路径降为只建锦囊（参考材料） |
| P8 | "导入即资产"在注入错误案例时，解题率或 S_tok 劣于正常导入 | 不成立：练习化改为可选 |

读数：墙钟（开题到终态的事件 ts 差）、成本倍数、解题率、并行折损率与四个子类、退回串行的次数与触发信号、资源冲突次数、`scope_violation`。另读未证明清单第 20 条：D、C 两组里实际出现的互不依赖 open Intent 的峰值与均值。

预登记阈值：

| # | 判据 | 不达标的动作 |
| --- | --- | --- |
| Q1 | D 组：adaptive 对 fixed1 墙钟 ≤ 0.7×、成本 ≤ 1.2×、解题率不降 | `max_sessions` 默认值改为 1，并行只在人显式开启时用 |
| Q2 | C 组：adaptive 成本 ≤ fixed1 的 1.05× | 退回串行的信号不灵，收紧阈值重测一次，仍不达标则 C 类签名默认串行 |
| Q3 | `fallback=off` 在 C 组的成本高于 adaptive | 不成立：退回串行是多余的规则，删除 |

| Q5 | 前置：G1 在 20 题上达标 | 不达标时能力三只保留资源占用（守门官）与分账（量具），并行度派生不做 |

## 5. 怎么跑、谁来跑

- 全部臂走评测台（`paoding_eval`），每条运行一条 `record.json` 加 `meta.json`（PR #74 的格式），收进 `docs/m1/readings/<批次>/records` 或 M2 起的 `docs/m2/readings/`。
- 预登记：阈值表、臂清单与题组清单的哈希以 input 类 Artifact 写进评测题组的开题事件（规格 8.3 规则 7）。改阈值就开新题组。
- 长时间运行推分支交给 GitHub CI（项目约定）；真模型的运行要 cz 本机的密钥，由评测线程安排。
- 成本按当前读数的量级估：q1 全栈每次约 $0.016。R 题组 7 条臂 × 12 模板 × 2 实例（B、B'）× 3 次约 500 次运行，加 A 实例与消融约 700 次；即使中等题的单次成本是 q1 的 20 倍，也在 $250 以内 [假设]。换成强档模型时按规格 8.2 重算，可能高一到两个数量级，届时先只跑 R-same。

## 6. 官知止审计接口

三项能力的每个感知官都进常设留出表（规格 8.6）：记忆召回、判据模板、切口先验、花费画像、并行度派生。里程碑的官知止审计照常重跑全部 organ-off 臂，并在归因表旁记录各官的退役距离：

| 感知官 | 退役距离 := |
| --- | --- |
| 记忆召回 | S_tok(记忆) 的 90% 区间下界（离 0 还有多远） |
| 判据模板 | 模型首轮自写判据的对照通过率 − 模板的对照通过率 |
| 切口先验 | 有无先验时切口命中率之差 |
| 花费画像 | 画像的花费预测误差 − 预测账（N3）的花费预测误差 |
| 并行度派生 | fixed1 对 adaptive 的墙钟比在 D 组上离 1 还有多远 |
