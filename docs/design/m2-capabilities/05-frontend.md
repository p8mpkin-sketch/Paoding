> 上位约束：[HMI 设计 v1.1](../hmi-design-v1.md)（五条禁令、四语域、一卡多端、`as_of` 回放）、[工作台设计](../web-workbench-v1.md)、视觉重做第四版（纸、墨、朱印、界栏、编号；原型在共享文件夹 `ui-redesign/v4/prototype/`，实施中的 PR #73 已合入、#76 待审）。
> 线框：`wireframes/*.png`，由 `wireframes/m2.js` 叠在 v4 原型之上渲染（放进原型目录、`index.html` 在 `screens.js` 之后加载它；`?s=wiz-recall|ws-recall|tongjian|redo|ws-lanes`）。数字全是示例。

## 0. 原则（不变的部分）

1. 前端仍是日志的读者：不调用模型，不算等级、不算记忆状态、不算并行度、不算节省率。这四样都由服务端派生，前端只排版。
2. 新增的写操作只有人的四个：开题时去掉某条召回（随开题批次）、`mem_pin`、`mem_forget`、标准案例导入（随开题批次，开练习题）。扩展版加 Playbook 的 `kit_publish`、`kit_reject`。全部带 `idem_key`，决策类带 `seen`。
3. 量具只显示、不驱动按钮：复做节省率不替人改默认值，并行度不提供"加宽"按钮，花费画像只作向导的预填值。
4. 语域：召回节点的标题是**叙述**，判据与复核结果是**证据**，切口先验、花费画像、节省率是**估值或读数**，钉住与遗忘是**人**。由数据来源查表决定（HMI §3.4）。
5. 用词延续 v4 的界面词：任务、尝试、会话、指导。本设计新增的界面词：记忆、通鉴、复核、走不通的路、判据模板、切口先验、花费画像、练习、复做、并行度、泳道、工具台账。

## 2. 交互流与状态

### 2.1 开题时带入记忆（界面 1、2）

```
向导第三步完成 ─▶ GET /v1/memory/match（环境键、签名键、题面）
   ├─ 无匹配：第四步只显示预算，记忆区写"这个环境与这类任务还没有记忆"
   └─ 有匹配：列出事实（默认全勾）、走不通的路（默认全勾，只作提醒）、花费画像（预填预算）
人取消勾选 ─▶ 本地草稿（不影响任何派生量）
开题 ─▶ POST /v1/problems：批次 = 召回判据的 input 类登记 + open_problem{recall, labels}
   └─ 201 ─▶ 工作区；记忆页签显示"开工前复核"进行中
   （不做"匹配结果已变"的拒绝：开题校验若去读通鉴的当前状态，题日志的重放就依赖了另一条日志。
     条目在这期间过期也无妨，复核会把它挡下。）
召回运行器 ─▶ 每条结果到达：复核行从"复核中"变为"通过"或"未通过"（SSE 事件驱动）
全部完成或 60 秒到 ─▶ 剩余条目标"未复核，只作提醒"
```

常设留出抽中"记忆召回"的题，第四步的事实区整块显示"本题被抽中作对照，不带入记忆"，不可改；这是量具的约束，不是人的选项。

### 2.2 通鉴里的条目（界面 3）

| 状态 | 章 | 可做的操作 |
| --- | --- | --- |
| 活跃 | 实线边框 | 钉住、遗忘 |
| 休眠 | 虚线边框 | 钉住（钉住后照常召回）、遗忘 |
| 过期 | 粗边框，文字"过期" | 遗忘；钉住按钮置灰并说明"钉不住已过期的事实" |
| 退役 | 删除线 | 无；出处链保留 |

遗忘是决策类操作：先弹出确认卡，卡上列出这条记忆被哪些任务带入过、在不在它们的解题链上；确认带 `seen`。通鉴页的时间轴（`as_of` 是通鉴日志的序号）可以回放"某一天通鉴里有什么"，与工作区的时间轴同一组件。

### 2.3 复做读数（界面 4）

只读。数据来自 `GET /v1/readings/redo`。标题句由服务端给的数值套模板生成（前端不做判断）：达标时"带上记忆，第二次省了 X"，不达标时"第二次没有省下来"，样本不足 30 对时右上角朱批固定为"方向性"。点哑铃图的一行进入该模板的配对运行对比（工作台设计 C7 的运行对比，等它的端点）。

### 2.4 并行（界面 5）

```
泳道视图：行 = 推理 + 每个 Explore 会话 + 每条被写占用的授权规则；横轴 = seq（不是墙钟，保证回放确定）
段的四种样式：割（实心墨）· 折（斜线）· 等待资源（虚线）· 资源占用（朱框）
并行度徽章：parallel {mode, width, reason} 原样显示；mode 切换的那个 seq 画一条朱线
拖时间轴 ─▶ 泳道按 as_of 重绘，只追加不重排（HT-14 的同一要求）
"工具"页签：选中会话的工具台账（命令、规则、产出被谁引用）；重复命令标朱
```

会话栏（左）在并行时显示每个会话占用的规则与读写；在串行时显示"可开但在等"的尝试与原因。

### 2.5 待办新增的项

| 待办项 | 触发 | 动作 |
| --- | --- | --- |
| 经验待审（扩展版） | 有 Playbook 候选 | 打开审批卡 |
| 练习题组完成 | 练习题组全部关题 | 查看读数（独立解出、借参考解法解出、未解出） |

记忆过期、退回串行都不进待办：它们是系统按规则处理完的事，只在通鉴与工作区里显示。待办只放"需要人"的事（v4 的朱红只标"需要你"）。

### 2.6 ⌘K

命令面板加三类结果：记忆条目（按标题）、资产（按名称）、练习题组。操作类加"导入标准案例""查看复做读数"。

## 5. 验收（前端部分）

1. 向导提交体里没有任何记忆状态或节省率字段，只有条目 id 与人去掉的条目（HT-2 的同类检查）。
2. 召回节点在列表、图、检视三处都带"[忆]"与出处，标题按叙述渲染。
3. 泳道在同一 `as_of` 两次渲染，段的位置逐像素相同（沿用 HT-14 的做法：只读 seq，不读时钟）。
4. axe：五个新界面 × 纸、墨、高对比三主题零违规（第一期 PR #73 的同一套用例）。状态章靠边框样式与文字区分，不只靠颜色。
5. 每个新界面都有对应的 `pd` 命令（HMI 禁令 5）。
