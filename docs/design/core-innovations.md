## 1. 项目信条

**一句话：一条确定性事件日志做骨架，判官定真伪，模型只在缝隙处出场，器官随模型成熟逐步退位。**

| # | 信条 | 一句话表述 | 违反的后果 |
| --- | --- | --- | --- |
| 红线 1 | 写入路径无模型 | 共享状态的校验与应用是确定性纯函数 | 不可复现、不可审计、调度无法多实例 |
| 红线 2 | 反幻觉不变量 | 被信任的证据只能是执行层直接产出的内容寻址 Artifact；E3 的判定回路里永远没有模型 | 模型自述混入证据链，幻觉式成功 |
| 红线 3 | 领域不进内核 | 领域词只出现在锦囊与判官配置 | 内核长成某个领域的专用形状 |
| 红线 4 | 删简律 + 官知止律 | 每个结构回答"下一代模型会不会吃掉它"；感知官带退役条款，守门官长存（判别式：**它弥补的是模型的缺陷，还是世界的性质？**） | 结构僵化，被下一代模型整体淘汰 |
| 红线 5 | 诚实对照 | 赢不过"薄外壳 + 强模型"（瘦基线/等成本重试）就删 | 自欺：复杂度没有换来任何东西 |

三条主线（规格 §2）：**判据先行**（Goal、带判据的 Intent、观察类论断走同一条判定路径）· **结构自识**（画像、难度、能力全由题目推出，难度也是结构）· **自我删简**（每个 T-1 结构带开关、消融臂与归因账）。

## 2. 核心架构（骨架一张图）

```
基座 = 一条事件日志 + 确定性裁决器 + 四个插拔接口
       （判官 / Worker Adapter / 执行层 / Blob 存储）

 人 ──(open/hint/approve/裁决/验收)──▶ ┌──────────────────────────┐
   司南×N（无状态、不含模型）─────────▶│ 解牛图：事件日志+纯函数裁决  │
        │ 起会话                       │  ├─ 图与等级（派生，不存储） │
        ▼                              │  ├─ Artifact 登记（投影）    │
  Adapter（代理工具 exec/submit/show）──▶│  └─ 预算账本（投影）        │
   ├─ 模型容器：CLI，只有文件工具        └────────▲─────────────────┘
   └─ exec ──▶ 执行层（执行容器：授权编译、按风险注入能力、采集留证）
                       │                        ▲ 洁净重放
                       ▼                        │
                 Blob 仓库（sha256）      判官运行器（判官容器）
                                        哮天犬（纯脚本看门狗）
```

- **六契约**：Problem(TaskSpec)、解牛图（事件日志）、Artifact 仓库（内容寻址 + 出处类别）、判官、Worker Adapter（双容器 + 三个代理工具）、执行层；预算是日志上的投影。
- **三机制**：司南（调度 + 扇出规则表 + Hint 通道）、模型经济（分层路由 + 异构判定）、通鉴/锦囊（跨题记忆，防投毒）。
- **协调基质可插拔**：九操作接口（submit/adjudicate/snapshot/stable_dump/cas/query/settle/replay/history）；M0 实现 = 事件日志（SQLite+reducer）；阡陌(git)/榷场(市场) 为规模化备选——基座不被任何一次基质押注绑架。

## 4. 这套设计是怎么来的（方法论本身是资产）

```
两路独立调研（Claude 六场景 ∥ ZCode 攻防谱系）→ 交叉合并 v2（重叠区独立收敛）
→ 架构 v0（ZCode）→ 对抗评审七条（Claude）→ v0.1
→ 绿地对照运行（全新上下文、零预设）→ 核心三角再次独立收敛
→ 基座规格 v1.0/v1.1 + 可运行参考模型（Claude）→ A1–A10 异议
→ 人的裁决（全采纳 + 三补充 + 一项自我撤回）
→ 双轨典故深读（总纲 ∥ 逐句对账，第三次收敛）→ D1–D6 裁决 → v1.2
```

可复用的方法：**多模型交叉评审、绿地对照（fresh-context 控制实验）、人的裁决否决权、典故作为设计语料**。本项目每一步重大设计都至少经过两个独立上下文的推导或评审。

## 5. 尚未被证明的东西（动工前的诚实清单）

1. **G1 生死线未跑**：编队（Reason+Explore）的价值未经证明——赢不了等成本重试 Bk 就按红线 5 删除，退回"瘦基线加判官"。典故对此不提供支持（原文单人无编队）。
2. **外壳税未知**：代理工具面对原生工具面的损耗，B1b 才能量出；超 5 个百分点先改工具面。
3. **knot"收拢优于加宽"是假设**：判官廉价的题上可能不成立（消融裁决）。
4. **所有成本数字是估算**：D7 才有第一批实测值。
5. **官知止的退役信号是预测**：信号本身要随模型代际校准。
6. **E1/E2 两级 vs 二值**：消融未跑。

本项目的主张分两种：**已机械化的**（写入规格、代码强制）与**待证明的**（M1 评测裁决）。成败标准已预先写死，不许赛后移动球门。
