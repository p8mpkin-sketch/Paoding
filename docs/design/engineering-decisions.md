# 工程决策记录（EDR-001）：语言、前端、部署、仓库

> 状态：提案（2026-11-17），待人裁决后由规格维护会话吸收进规格附录｜作者：ZCode（评审方代拟，属实现层常规决策，非核心创新）
> 原则：这批决策是**实现载体不是架构赌注**——每条都过删简律（换掉它的成本必须低）；约束已把答案锁得差不多（参考模型=Python、存储=SQLite、单机、CLI 绑定），本文做的是钉死与留痕。

## D-1 开发语言：Python 3.12+，单语言贯穿 M0–M3

- **范围**：图服务（事件日志+reducer+投影）、Worker Adapter、判官运行器与内建判官、执行层、`pd` CLI、哮天犬、评测台——全部 Python。异步用 asyncio（事件量 200/s 量级，足够）。
- **理由**：① 参考模型（kernel.py + 47 测试）即 Python，等级函数/消费门/reducer 逻辑可直接搬进真实实现而非重写——消除一整类翻译 bug；② reducer 是纯函数，瓶颈在 IO 与模型调用，不在计算（10⁴ 节点全量重算 70ms 已实测）；③ 单人 2–3 周工期，单语言切换成本最低；④ CLI 子进程/Docker SDK 生态成熟。
- **备选与否决**：Go（适合网关与分发，但 M0 无分布场景，且与参考模型断裂）；Rust（正确性好、工期不允许）。
- **退出条件（官知止式）**：M2 压测显示单写者/投影成为实测瓶颈 → 仅对瓶颈组件局部 Go 化（候选：端点代理→模型网关）；语言整体迁移永不发生——契约接口（九操作、三代理工具、判官接口）本就是语言中立的。

## D-2 前端：M0–M1 无；M2+ 可选只读查看器

- **M0–M1**：人机通道 = `pd` CLI（open/hint/approve/status/report）；观测 = 确定性投影 + `GET /events` 长轮询。终端即界面。
- **理由**：写路径唯一（红线 1）；交互式 UI 在早期必然演化成第二个写入口或第二份真相。规格 M0 不做清单已含"图形界面"。
- **M2+ 可选**：只读 web 查看器——静态页消费事件流投影（图、等级、预算、行情），SSE 推送，**零写入权限**。标注：感知官 [T-1]（可视化是给人看的感知辅助；退役信号=没人看）。预估一两天工作量，不进关键路径。
- **永不**：交互式控制 UI 直接写入。UI 永远只是图服务 API 的另一个客户端；任何"按钮→写"都必须走与 `pd` 相同的提议-裁决通道。

## D-3 部署环境：M0–M1 单机；分布按里程碑递进

| 里程碑 | 形态 |
| --- | --- |
| M0–M1 | 单机（一台 Linux/macOS 或 VM）。Docker 跑模型容器/执行容器/判官容器；图服务、Adapter、判官运行器、哮天犬为本机进程，Unix socket 通信；SQLite 单文件（WAL）+ 本地 blob 目录；docker-compose 可选封装 |
| M2 | 同上 + 并发与单写者压测 |
| M3 | 同上（第二场景接入不改变部署） |
| M4 | PostgreSQL + 对象存储 + 模型网关（多组件，仍可单机或多机） |
| M5 | 多机：子题/托管、题组层榷场、百到千并发 |

- 沙箱分级照规格：M0 用容器；强对抗场景升 VM；bwrap 为轻量备选。

## D-4 仓库结构：monorepo，目录即组件边界

```
paoding/
  pd/               # 人的通道 CLI
  graph/            # 图服务：事件日志、reducer、投影、租约
  adapter/          # Worker Adapter：任务包渲染、代理工具、会话状态机
  executor/         # 执行层：授权编译、容器、采集登记
  judgebox/         # 判官运行器 + 内建判官（replay/exact_match/seal_check/lean_check）
  watchdog/         # 哮天犬（纯脚本）
  eval/             # 评测台：题集、四臂运行器、归因表、预测账投影
  reference-model/  # 已有（等级函数参考实现与测试）
  docs/
```

每个组件目录内放一页 SPEC.md 声明其实现的契约接口；跨目录依赖只允许经由契约接口（依赖单向：组件→信任根，同蓝图 §2.2）。
