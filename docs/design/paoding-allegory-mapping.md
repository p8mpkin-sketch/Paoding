# 庖丁解牛 · 典故-架构对应与「官知止」设计总纲

> 日期：2026-11-17｜性质：设计宪法级文档（与 [base-layer-spec-v1.md](./base-layer-spec-v1.md) 互补：规格定"怎么建"，本文定"为何而建、何时拆"）
> 核心目标：**庖丁的设计不仅要满足眼前，更要兼容未来。**

---

## 0. 总纲：以「官知止」为终极形态

> 「方今之时，臣以神遇而不以目视，**官知止而神欲行**。」——《庄子·养生主》

庖丁自述的三阶段成熟：

| 阶段 | 所见 | 系统形态 |
| --- | --- | --- |
| 始解牛 | 无非牛者——把问题当铁板一块 | 弱模型 + 蛮力重试（族庖，月更刀） |
| 三年之后 | 未尝见全牛——只见结构与缝隙 | **当前架构**：图、视图、判官、控制器（良庖 → 庖丁之间） |
| 方今 | 以神遇而不以目视，官知止而神欲行 | 未来：结构内化于模型，感知器官退居次位 |

**本文确立的设计总目标**：庖丁的成功终态不是系统的无限增厚，而是**器官的逐步退位**。模型每一代变强，都应有一批"官"退役，而骨架（契约与守门结构）不动。未来兼容性 = 稳定的契约 + 可退役的器官 + 显式的退役协议。

## 1. 官知止律（The Organ-Retirement Law）

### 1.1 定义

- **官**：一切为弥补*当前模型*的感知与自控缺陷而建的结构（三层视图、独立规划者、模型复核梯、扇出控制器、输出截断……）。
- **神**：模型本身 + 正确性不变量（五条红线）。
- 三条律令：
  1. **官不得进入正确性路径**——正确性只依赖确定性代码与判官（红线 1/2 的推论）；官只影响效率与成本，撤掉官系统仍正确，只是变贵变慢。
  2. **每个官必须携带退役条款**——一条可测量的模型能力信号，信号翻正即退役（消融臂常态化为 `off`，随后删除代码）。
  3. **官的依赖方向单向**——官依赖契约，契约永不依赖官；换官、撤官不触发契约版本升级。

### 1.2 官的两分类：感知官与守门官

判别式只有一句话：**它弥补的是模型的缺陷，还是世界的性质？**

- 模型的缺陷会随代际消失 → **感知官**，设退役条款；
- 世界的性质不会（不可逆动作存在、资源有涯、对抗面存在、会话会死）→ **守门官**，长存，只随威胁模型演变。

### 1.3 退役条款表（v1，随规格版本共同维护）

**感知官（随模型成熟退位）**

| 官 | 弥补的当前缺陷 | 退役信号（可测量） | 退役动作 |
| --- | --- | --- | --- |
| 三层视图与下钻 | 长上下文注意力衰减（lost-in-the-middle） | 满量 dump 与下钻版解题率之差 ≤ 1 题（20 题集）且成本不升 | `view=full_dump` 常态化，删视图层 |
| Reason 独立规划者 | 单会话跨小时计划漂移 | METR 口径的任务时长超过目标场景时长一倍，且单会话无漂移（归因表 Reason 在链率→0） | 并入 Explore，单循环自维护计划 |
| E1/E2 模型复核梯 | 同源模型互证的回声室 | E2 误晋级率低于判官自身误判率（互证严格优于自证） | `ladder=binary` 常态化 |
| 扇出控制器（八仙） | 模型不会自行分配并行探索 | 模型自带 test-time 并行搜索且预算自管，固定并发消融不劣 | 固定并发，删规则表 |
| 代理工具输出截断/摘要 | 上下文与成本 | 取消截断不伤成本与解题率 | 放宽上限直至移除 |
| 画像三轴→外壳模板选择 | 模型不会自选策略 | 模型自选策略不劣于推导模板 | 三轴仅作报告字段 |
| Bootstrap 之外的厚路径 | 强模型直解即最优的题目占比低 | Bootstrap 在题集上的独占解出率→0 | 厚路径收缩（注意：这是唯一"越强越常用"的反向官——它就是结构消失的方向本身） |

**守门官（长存，与模型强弱无关）**

| 官 | 长存的依据（世界的性质） |
| --- | --- |
| 判官与 E3/X 证据等级 | 正确性的定义：达成与否必须独立于任何模型的自述（红线 2） |
| 预算硬顶 | 「吾生也有涯，而知也无涯」——资源有涯是宇宙常数 |
| r2 审批门 | 不可逆性是世界的属性，不是模型的属性（「怵然为戒」是德性，不是器官） |
| 双容器 / 密钥隔离 / 代理工具 | 对抗面来自环境与目标内容（提示注入、逃逸），不随模型变善而消失 |
| 事件日志与审计 | 「薪火相传」——会话必死，跨会话持久是系统的定义 |

### 1.4 工程机制（把律令落进流程）

- 既有：T-1 标签、消融开关、归因表（规格 §2、§8.4）。
- 新增三条：
  1. **退役条款显式化**：上表并入规格附录，新结构入库时必须声明"我是感知官还是守门官、退役信号是什么"——声明不了的按感知官处理（默认可拆）。
  2. **官知止审计**：每个里程碑（M2 起）重跑全部 organ-off 消融臂，在归因表旁记录各官的**退役距离**（信号离翻正还有多远），写入里程碑报告。
  3. **退役是事件不是遗忘**：官退役后在规格 changelog 记一行（谁、何时、什么信号翻正）——系统自己的"解牛史"就是通鉴最好的素材。

## 3. 章首与章尾：一章的两端就是两个契约

《养生主》**首句**：「吾生也有涯，而知也无涯。以有涯随无涯，殆已。」
—— **Budget 契约**的原文。预算硬顶、续期门、"unsolved + 已排除路径"为合法输出，全是"不以有涯随无涯"的工程化。

《养生主》**末句**：「指穷于为薪，火传也，不知其尽也。」
—— 薪尽火传 = "个体会死，图存续"（sapper）= **事件日志**的跨会话持久性。

一章之首是预算契约，一章之尾是日志持久性。项目以这一章命名，然后不知不觉实现了它的首尾两端。

## 4. 四个新提案（供规格 v1.2 评估）

1. **族协议扩展**：谨慎区从"不可逆动作（r2）"扩展到"复杂度聚集"。派生规则：某 Intent 前提子图中争议边密度超阈值（如 ≥3 条未决 `contradicts`）时，即使全 r0 也降并发、上调 `verify_share`、Reason 任务带 `tangled` 标志（与 `reflect` 同机制）。零模型成本，纯派生。
2. **善刀终局协议**：close 流程显式固定为三步——**四顾**（守护项 + 影响面检查 + 归因行）→ **定终态**（solved/accepted/unsolved，且必须发生在四顾之后）→ **藏刀**（容器销毁、密钥轮换、会话归档、Playbook 蒸馏入通鉴）。把已有零件组成有名有姓的协议。
3. **刀刃保持指标**：M1 评测增加"无效刀刃率"——花在读了未被引用的节点、修复轮、重复试探上的 token 占比。刀刃若新发于硎，应当可以度量。
4. **通鉴地位升级**：庖丁的功力是"所解数千牛"喂出来的——十九年刀刃如新靠的是积累的牛体知识，不是单次发挥。通鉴是复利资产与长期护城河：M1 的人工复盘即应开始喂它，M4 之前不建自动管线但**归因表从 M0 起就是通鉴的原材料**。

## 5. 典故的边界（诚实清单）

- **牛是死的**：不反抗、不变动、无对抗者。动态环境（`ttl_s` 判据有效期）与对抗场景（A&D）超出比喻范围——判据有效期与守护项是必要的"超出典故"。
- **单人双肢**：多肢协调容易，"多庖丁"协调（上千 Worker）典故未讲——那是榷场（市场基质）要解决的问题。
- **无时间压力**：一次解牛内无截止时间——预算墙钟是我们的补充，非典故所赐。

比喻止步之处，正是设计必须超出典故之处。

- 本文**不改任何契约**；§1.3/§1.4 与 §4 的提案供 v1.2 评估吸收。
