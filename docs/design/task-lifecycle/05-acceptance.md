# 05 验收标准

> 每条写成“人做什么、看到什么才算做好”。第三栏是把这条判断固定下来的自动化检查，实现 PR 必须带上它；第四栏是对应的缺口或已有位置。
> 已有的 HT-# 是 HMI 设计的验收编号，沿用不改。
> v0.9（开放道修订）：AC3.3 改写（判据表达不出不再拒题）；AC8.1 限严格道；AC8.4 改为八种点位；新增开放道的 AC3.5、AC6.4、AC7.3、AC7.4、AC8.8、AC8.9、AC9.3、AC9.4、AC10.4–AC10.6、AC11.4、AC11.5。开放道第一步自己的验收（十条提示词）在开放道 §11.1，由测试方跑，这里不重复。一句话开题自己的验收（kaiti §10）不在这里重复，只在 AC1–AC4 引用。
