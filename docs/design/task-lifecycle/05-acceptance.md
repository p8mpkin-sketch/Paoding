# 05 验收标准

> 每条写成“人做什么、看到什么才算做好”。第三栏是把这条判断固定下来的自动化检查，实现 PR 必须带上它；第四栏是对应的缺口或已有位置。
> 已有的 HT-# 是 HMI 设计的验收编号，沿用不改。一句话开题自己的验收（kaiti §10）不在这里重复，只在 AC1–AC4 引用。
