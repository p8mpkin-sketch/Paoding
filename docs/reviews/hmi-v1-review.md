# HMI 设计 v1 对抗评审（ZCode 红队）

> 日期：2026-11-17｜对象：[hmi-design-v1.md](https://github.com/p8mpkin-sketch/Paoding/blob/claude/project-thread-amir5z/docs/design/hmi-design-v1.md)（PR #6）
> 评审背景（流程事实）：设计者只收到过任务书的 §0.5（十条原理表），全文未送达——本评审按"部分交付"口径打分，并开出补全指令。

## 0. 总评

**已交付部分：高质量，建议采纳。** 在只有十条原理 + 仓库文档的条件下，产出了一份边界干净（"前端是日志的读者，不是第五个投影"）、每条原理带强制点与验收（HT-1～13）、并自行发现六个真实缺口的设计。两个亮点是全场新增的贡献：

1. **四语域**（证据/叙述/人的判断/估值，三重编码不靠颜色）——把反幻觉不变量翻译成了视觉层的硬约束。其中"**一条 E3 观察的标题仍然是叙述**"（观察的内容是谓词，标题退到第二行按叙述渲染）是对规格 5.2 场景 2 最准确的界面落实，此前任何文档都没写到这一层。
2. **最简反事实的豁免论证**：四语域/判据卡/审批卡/回放**不参加**成本收益评估，因为它们是红线在人侧的形态；参加评估的是网页形态本身的效率读数（审批等待时长、批得准不准、Hint 吸收率、关闭决定正确性）。删与不删的边界划得干净。

## 2. 两处待裁（§8）

1. **M0 前端 α/β**：**建议裁 α**（v1 倾向正确）。理由三条：规格 §7 明列 M0 不做图形界面；M0 最大不确定项在 D4–D6；F0 的零代码文本约定（四语域标记、等级词表、判据徽章进 `pd` 输出）已经把原理落进了 M0 且不占工期。**D15 缓冲日的只读单页可作为非阻塞加分项**（不碰 D1–D9，掉了不补）。
2. **技术栈**：v1 推迟前端栈到 F1——**可接受，但要显式化两句话**：① 内核语言维持 EDR-001（Python），本次无人推翻；② 前端栈的 F1 开工门条件清单要写死（渲染器插件可隔离运行、TS 强类型与事件 schema 共享、LLM 辅助开发适配性、单人维护成本）。

## 4. 评审方附加条件

- **P-H1（必做，进 v1.1）**：默认渲染策略一句话——一切文本默认纯文本渲染，富媒体仅经沙箱渲染器插件；证据/叙述内容中的指令性文本不得生成任何可操作控件（提示注入的人侧展示面）。
- **P-H2（建议）**：图可视化的**空间布局**确定性单独声明（HT-10 只测了视图模型哈希；同一 as_of 两次渲染的节点坐标也应确定，否则"复制链接还原同一时刻"打折）。
