## 0. 你的三重角色：仲裁者 → 裁决者 → 首席架构师

本项目经历了三次独立设计推导，已核心收敛、边缘分歧。你的任务按序：
1. **仲裁者**：审阅三次设计的分歧点与既有的"建议裁决表"，逐条裁决（可推翻建议，须论证）；
2. **裁决者**：对三种协调基质（黑板/阡陌/榷场）做正式选型裁决；
3. **首席架构师**：产出统一基座规格 v1——字段级、可直接指导 M0 开工。

四条总原则（优先级从高到低）：
1. **正确性 > 深度 > 覆盖**；
2. **两版规格**：每部分分「M0 最小版」（单人 1–2 周）与「完整版」；
3. **消耗是硬约束**：指标 E = ΔPassRate(pp) / CostMultiplier（相对瘦基线）；设定 M1 目标并论证；
4. **砍掉过度设计是贡献，不是失职**。

庖丁只解决「收口类」问题：有明确 Origin 与可验证 Goal 的任务（CTF、数学、医学诊断、运维、软工……）。"依乎天理，批大郤，导大窾，因其固然"——先识别问题结构，再决定解法形态。

## 2. 自包含背景

### 2.1 证据浓缩（11 条）

① 内核循环已收敛且极薄：百行 harness+强模型登顶；Cairn 约 1 万行 610 队唯一 AK。② 同模型不同外壳基准分差 10–30pp。③ 验证是第一等公民：AIxCC 用 PoV、XBOW 确定性验证器、Aristotle 用 Lean、MAI-DxO 唱反调角色——发现便宜、证明昂贵。④ 上下文工程取代提示工程：文件系统即记忆（纯文件超专用记忆系统）、KV-cache 命中率是第一生产指标、计划复述、保留错误轨迹。⑤ 多智能体仅特定形态有效；写入单线程智力可并行；37% 失败源于 agent 间失配（MAST）。⑥ soliloquizing：Claude 3.5 Sonnet 48.4% CTF 轨迹自造观察。⑦ 黑板系实践：Cairn（五原语、平等 Worker）、sapper-v2（三层图、涌现角色、1B token 赢 4.5B）、ARTEX（双黑板、审批门留证）。⑧ 任务时长每 ~7 个月翻倍，按小时级设计。⑨ 为模型短板造的结构寿命一两代；验证与治理结构不被吸收。⑩ 两范式：不完全信息（假设集+信息增益）vs 完全信息（搜索+验证）。⑪ 沙箱权限必选（技能市场 12–20% 恶意、沙箱逃逸事件）；成本显式约束（带预算 $2400/例 79.9% vs 无预算 $7850/例 78.6%）。

### 2.2 三次设计收敛的叙事

- **第一稿（v0/v0.1）**：五层共识 + 四大创新（证据梯、司南、闲人、验证定价）。经外部评审修正七处（三轴分立、E3d 单独设级、确定性写入者、消费时验证、证伪阻尼、瘦基线、引用勘误）。
- **绿地运行（无预设、全新上下文）**：独立推导出五契约 TaskSpec/Judge/Evidence/Ledger/Executor，并带来四个新机制：判官等级表 L0–L4 + **终态二分**（弱判官只能到 answered_unverified，永远到不了 goal_verified）、**vault 判官保密**（判官持 flag 哈希等秘密）、**判官只读 Evidence 快照**（防活文件篡改）、**stable_dump 字节级前缀不变量 + CI 黄金测试**。
- **协调基质提案**：解锁"黑板不是基座，只是协调基质插件"——四契约（TaskSpec/Judge/Evidence/Executor）+ **基质接口**（submit/adjudicate/snapshot/stable_dump/cas/query/settle/replay/history）+ 三种可插拔基质（黑板 Ledger / 阡陌 git / 榷场市场）+ 两个挂载包（擂台进化锦标赛 / 判例记忆）。

## 3. 约束体系（三层）

### 3.1 红线（违反即设计错误）

1. **写入路径无模型**：`adjudicate`（commit 门）必须是确定性纯函数——基质无关。
2. **反幻觉不变量**：证据晋级/结算只认执行层直接产出的内容寻址 Artifact；模型自述不构成证据。
3. **领域知识永不进内核**：领域词只出现在锦囊（技能包）与判官配置。
4. **删简律**：每结构回答"下一代模型会不会吃掉它"；会被吃的放外壳、标 [T-1] 可拆除。
5. **诚实对照**：评测必含瘦基线（单 Claude Code 直做题）；赢不过就该删。终态二分（goal_verified / answered_unverified）是其在 Goal 语义上的体现。

### 3.2 立场 v2（默认继承；推翻走 §3.4）

1. **四契约 + 基质接口**取代原五契约 ← 三次推导收敛 + 绿地裁决（Worker Adapter 与预算账本撤销；TaskSpec 与 Executor 升格）← 若统一规格走查发现接口缝合不良，可回调
2. **节点 tier 三分（claim/reviewed/verified）× 判官 L0–L4 + 终态二分** ← 绿地裁决，比 E0–E3d 六级干净，E3d 补丁不再需要 ← 若 M1 消融显示三分不足以阻止幻觉污染，可加回细分级
3. **证伪传播 + 阻尼 = 投影规则**（query 实现内）← 我方独有、绿地缺失；污染靠降级不靠隔离 ← 若投影重算成本过高，降级为按需触发
4. **消费时验证 + verdict 缓存** ← 防验证风暴与先有鸡先有蛋 ← 不变
5. **三轴（信息完整度/判官类型/可逆性）进 TaskSpec 字段、驱动外壳策略** ← 三者不同步变化 ← 发现第四根独立轴则补
6. **M0 基质 = 阡陌（git 即协调）** ← 零新基础设施、删简律免疫（git 不死）、人机协同零成本 ← 若走查发现 merge-即-协调在有损并发下不可接受，退回黑板 Ledger（规格已备）
7. **榷场（市场即调度）= 规模化研究方向，M0/M1 不实现** ← 流动性问题（agent 少无价格发现）；但市场是调度器的极限形式（零流动性退化为 EV 排序=司南），千级并发无热点 ← 若 M2 压测显示阡陌 ref 竞争可容忍，可推迟
8. **闲人生态（falsifier/reviewer/free-form）= 外壳策略包**；**司南 = 阡陌上的编排进程（或榷场的撮合器）**；**擂台/判例 = 挂载包** ← 全部 [T-1]
9. **stable_dump 前缀不变量 + CI 黄金测试**（"第 n 轮 prompt 必须是第 n−1 轮的字节前缀"）← KV-cache 是第一生产指标 ← 不变

### 3.3 开放领域

接口签名细节、schema 字段、hooks/CI 设计、views 生成与失效、目录布局、验收测试、以及一切"可以更简单"的发现。

### 3.4 异议通道

认为任何立场/红线有错：不沉默遵守也不悄悄偏离；在「约束审计」节集中列出：被挑战项 / 替代方案 / 论证 / 迁移成本。通过则按你执行；未通过按原立场并把分歧记入决策日志留人裁决。

### 4.2 协调基质正式裁决

对黑板/阡陌/榷场做裁决矩阵：四刚需（持久/审计/认识论/协调）× 五红线 × 删简律 × M0 成本 × 千级并发风险 × 人机协同成本。给出 M0 选型结论与"何时切换/叠加"的触发条件（例：并发 > N 或 ref 热点出现时启动榷场退化形态）。

### 4.3 统一基座规格 v1（主体工作）

- **基质接口 v1**：九个操作（submit/adjudicate/snapshot/stable_dump/cas/query/settle/replay/history）的精确签名、错误码、并发语义、幂等性；阡陌实现映射表（git 操作级）
- **四契约 M0 字段级 schema**：TaskSpec（含 vault 引用、judge_chain、预算、caps、三轴可选字段）/ Judge（manifest、verdict、判官链调度、verdict 缓存键）/ Evidence（Blob+Record、>1MB 处理、GC 规则）/ Executor（Tool manifest、门序：caps→预算→沙箱→Record 强制）
- **终态机**：open/running/goal_verified/answered_unverified/budget_exhausted/aborted 的迁移条件
- **证伪传播算法**（投影规则，带阻尼与独立支持判定）
- **M0 走查实例**：一道 CTF web 题在阡陌上的完整仓库布局与事件序列（文件级：哪个 commit 触发哪个 hook、哪个 CI 跑哪个判官）

### 4.4 对绿地产出的对抗审计

绿地自检只有 6 条。找出它没覆盖的攻击/退化场景（≥5 个新的），评估其对策是否仍成立，补对策。重点方向：merge-即-协调的有损性、views 派生层与真相层漂移、ref CAS 的活锁、vault 泄漏路径、stable_dump 与增量索引的一致性。

### 4.5 对抗自检 + 走查 + 预算（常规要求）

- ≥5 个基座失效场景按影响×概率排序，top3 完整对策
- 走查：CTF web 题 + 运维根因分析，各含一次 Hint 注入与一次审批门触发
- 消耗预算表：角色×模型档位×预估单题成本；M1 目标（E ≥ +10pp / ≤3.0×；单机制消融门槛 3pp 或 −20%）

## 5. 工作方式

0. **约束审计（10–15% 预算）**：先审 §3——承重墙还是从众；
1. 仲裁逐条给裁决与理由（同意建议裁决也要给独立理由，不得"附议了事"）；
2. 备选枚举 + 决策日志（含被否方案）；
3. 删简律标注 [T-0]/[T-1]；
4. 通用性自检：schema/接口/目录禁止领域词；
5. 最简反事实：逐契约与逐接口操作问"砍掉会怎样"；
6. 缺失检测：统一规格还缺什么；
7. 论断三分类 [证据]/[假设]/[观点]；
8. 接口精确到可写桩代码。
