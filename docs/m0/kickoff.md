## 2. 仓库结构与实现纪律

组件目录（EDR-001 D-4 + sinan/）：`pd/ graph/ adapter/ executor/ judgebox/ watchdog/ sinan/ eval/`。每组件一页 SPEC.md（契约接口 + 官类声明三类制 + 退役信号/启用条件）。跨组件只走 contract，方向单向。

核心原理 → 代码检查点（评审方按此逐 PR 验收）：

| 原理 | 检查点 |
| --- | --- |
| 写入无模型（I1） | reducer 纯函数：不读时钟、不做 IO、不调模型；等级函数从参考模型逐字节搬运（CI 比对两份一致） |
| 反幻觉（I2） | 输出由执行层容器外采集登记；authored 不入 grounds；观察必须带 check；判官洁净容器重放；答案保密部分只在判官环境内可见 |
| 领域不进内核（红线 3） | 判官=配置目录、资源种类=插件；CI 领域词扫描内核目录 |
| 删简+官知止（红线 4） | 每个 T-1 结构带开关；SPEC.md 三类官声明 |
| 诚实对照（红线 5） | B1/B1b 运行器与评测台同仓同代理同计量 |
| 依乎天理 | 画像完全派生，代码无人填三轴入口 |
| 刀刃若新 | 任务包前缀字节稳定（CI 黄金测试）；回显 8KB 截断；判官程序化优先 |
| 怵然为戒 | r2 审批一次一租约；通行凭据按次发放 |
| 吾生有涯 | 端点代理逐请求计量+超额拒绝；50%/80% 预算标记 |
| 薪火相传 | 事件日志+按题哈希链+快照+确定性重放 |
| 善刀而藏 | close 三步：四顾清单→终态→销毁/归档/归因行 |
| I7/I8 | 摘录登记规则（M3 留接口）；估值事件进不了 level()/gate()（性质测试常驻 CI） |
| F0 前端约定 | `pd` 文本输出带四语域标记（[证据]/[叙述]/[人]/[估]）、等级词表、判据徽章 |
