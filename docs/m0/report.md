### 模型行为亮点

DeepSeek V4.1-Flash 在全栈模式下展现了教科书级的解题方法论：

```
"先取 schema 优于猜表名：消掉表名/列名/存储形态三个未知"
"schema-first：sqlite_master UNION + 定向 UNION + 登录闭环（共 3 请求）"
"R3 正常登录闭环成功：admin/<answer> → Welcome back，sha256 与判据一致"
```

闭环验证 + 分阶段计划 + 错误归因——**模型能力完全够用，瓶颈全在基础设施**（已全部修复）。
