# 异议报告 005：网页前端 F1 落地时发现的规格缝隙

> 日期：2026-11-17｜对象：HMI v1.1 §3.4、§3.5、§3.8、§5、§11、§13、§14；任务书“任务二”｜状态：待裁决
> 性质：都是分期、端点形状与取值层面的缝隙，没有改架构。实现先按“现行取值”落地，裁决不同再改。

| # | 缝隙 | 现行取值 | 请裁决 |
| --- | --- | --- | --- |
| 1 | 任务书把交互层（向导、Hint、待办、审批卡）放在 F1；HMI §5 把它们放在 F2，且依赖 H2 的 `seen` 与 `stale_view`（M1）。M0 的内核也不认 `pause`、`resume`、`extend`、`budget_add`，续期卡与争议卡返回 `not_enabled` | 交互层照任务书做了。批准与拒绝带 `seen {seq, card_hash}`，M0 不校验，前端自己比对卡片哈希并在变化时要求重新确认。续期门对话做了但真图服务上显示“暂不可用”；暂停与恢复没做按钮 | 确认 F1 的范围；`seen` 校验是否提前（同 004 第 4 条） |
| 2 | HMI §14 要求前端类型由 Python 一侧导出的 JSON Schema 生成；目前没有导出 | 类型手写，另录一份真图服务的应答做契约测试：类型吃得下真应答，假后端与真图服务各端点的键集合相同 | 导出放在哪个里程碑；就绪后类型文件整体替换 |
| 3 | H1“r2 缺回退时禁用批准”，而内核 M0 拒收 `rollback` 字段（004 第 8 条的现行取值是 M0 不禁用，与 `pd` 一致） | 网页按 HMI 字面禁用，比现行取值严：M0 的 r2 Intent 在网页上批不了，只能用 `pd approve`。HT-13 只要求 `pd` 能做网页能做的事，这个方向不违反 | 随 004 第 8 条一并裁决；改成只听卡面的 `approve_enabled` 是一行 |
| 4 | H6 的“无证据根”说的是整条前提链；图服务的 `no_evidence_root` 只看节点自己的 grounds。链经过一条 Intent 时算不算，也没有写 | 前端按结构沿 `premises` 展开（只走结构，不算等级），链上任何节点有 grounds 或有带证据的裁决就算有根；经过 Intent 的链照样往上走 | 定义以谁为准；建议图服务给出链级字段，前端删掉这段展开 |
| 5 | §3.8 图可视化的启用条件是节点数超过 50；交付标准要求“渲染图”，而示例题都不到 50 个节点 | 默认按 50 的条件；加一个本机开关（`paoding.graph_view=always`）强开，界面上是一个复选框 | 确认开关可留；或降低条件 |
| 6 | §4 的读数面板列了归因、折损、切口命中率、校准、留出、退役距离、学习曲线，§11.2 没有对应的读端点 | 只显示能从 `/problems` 与 `/budget` 读到的量（每解成本、按角色分项、验证池）；其余逐项写“暂不可用” | 这些读端点归哪个里程碑 |
| 7 | 时间轴刻度（§10.4）要全部事件的种类；现在靠 `/events` 分页读全量，长题上是浪费。Hint 的时间也不在视图里，只能从事件的 `ts` 取 | 冷启动分页读完 `/events`（每页 1000），之后跟流 | 是否加一个只给刻度的读端点；Hint 节点是否带 `ts` |
| 8 | §13.2 写的是浏览器带 `Last-Event-ID` 重连。`EventSource` 冷启动时带不了这个头，而图服务在没有游标时从链头之后开始，中间会漏 | 用 `fetch` 读 SSE，自己带 `Last-Event-ID`，自己看断连；无缺靠按题的 `prev_hash` 核对，缺了用 `/events` 补 | 确认；或让流接受 `?after=` |
| 9 | 实时视图要与回放同路（HT-10），所以每到一条事件就按它的 seq 取 `status`、`view`、`budget`、`work` 四份投影，一条事件四个请求 | 照此实现；只保留最后一次请求的结果 | 事件密集时是否要一个合并的读端点，或让流里带 `view_hash` 以便跳过没变的投影 |
| 10 | `/v1/templates` 的 `data` 是任意 JSON，§3.2 说“前端只解释字段映射”，但没有定字段名 | 按暂行字段名取预填值（`fields.scope`、`fields.goal`、`fields.budget`、`fields.materials`、`judges`），取不到就留空；目录为空时提供“不用模板” | 模板的字段约定 |
| 11 | §13.3 没有写人的令牌在浏览器里放哪 | 存本机 `localStorage`，只随写请求发出；构建产物的 CSP 只许同源连接 | M1 是否改成启动时注入或同源 cookie |
| 12 | Goal 没有节点端点（`/v1/nodes/goal` 不存在） | 目标的判据卡取自 `status.goal.predicate` | 确认 |
